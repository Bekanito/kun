# Kün — ИИ-инспектор солнечных станций

**Kün** («солнце» по-казахски) находит сломанные и запылённые панели на солнечных станциях Казахстана
по снимкам дрона-тепловизора и считает, сколько тенге станция теряет каждый день.

- В Казахстане 46 солнечных станций общей мощностью 1 222,61 МВт (Kapital.kz, 2025).
- В среднем станции теряют **5,08%** мощности из-за дефектов; на станциях с регулярными облётами дронов — около 3% (Raptor Maps, Global Solar Report 2026).
- Каждый потерянный кВт·ч солнца город добирает углём: ТЭЦ дают 66,2% электроэнергии страны (Kapital.kz, 2024).

> Демо-данные, станция условная.

## Что умеет платформа

| Часть | Файл | Что делает |
|---|---|---|
| Фронтенд | `public/index.html` | Карта станции с дефектами, снимок тепловизора, «что чинить первым», облёт до/после ремонта, калькулятор окупаемости |
| Логика | `public/engine.js` | Станция 50 МВт, дефекты (комбайнер, цепочка, инвертор, пыль, горячая точка, диод, трава), пересчёт кВт → ₸ |
| Бэкенд | `api/inspection.js` | `GET /api/inspection?flight=1\|2` — результат облёта |
| Бэкенд | `api/value.js` | `GET /api/value?mw=26.6&tariff=34.61` — потери станции, что вернёт Kün, цена, окупаемость |
| Бэкенд | `api/workorder.js` | `GET /api/workorder?flight=1` — наряд-задание для бригады |

Фронтенд берёт данные с бэкенда. Если сайт открыт как статика (например, GitHub Pages), тот же `engine.js` считает в браузере.

### Пересчёт в деньги
- 1 400 кВт·ч на 1 кВт панелей в год на юге Казахстана — допущение.
- Тариф 34,61 ₸/кВт·ч без НДС — фиксированный тариф для СЭС (ПП РК № 645 от 12.06.2014).
- 1 кВт потери ≈ 132,8 ₸ в день.
- Цена Kün 300 000 ₸ за 1 МВт в год — наше предположение.

## Запуск

Нужен только Node.js 18+, зависимостей нет.

```bash
npm start
# http://localhost:3000
```
